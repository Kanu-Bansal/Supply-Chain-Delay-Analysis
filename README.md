# 📦 Supply Chain Delay Analysis & Prediction

## 📌 Project Overview
This project analyzes delivery delays in an e-commerce supply chain 
and predicts high-risk shipments using Machine Learning (Logistic Regression).

## 📊 Key Insights

| Metric | Value |
|--------|-------|
| 📦 Total Orders Analyzed | 96,476 |
| ⏰ On-Time Deliveries | 89,941 |
| 🚨 Delayed Orders | 6,535 |
| 📉 Delay Rate | 6.77% |
| 📅 Avg Delay (when delayed) | 10.62 days |
| 🚚 Avg Delivery Time | 12.09 days |
| 🔴 High Risk Orders | 138 |
| 🟡 Medium Risk Orders | 2,502 |
| 🟢 Low Risk Orders | 93,836 |
| 🗺️ Most Delayed State | AL (Alagoas) |
| 🤖 Model Accuracy | **95.89%** |

## 💡 Business Findings
- **93.23% orders** are delivered on time — strong supply chain overall
- When delayed, average delay is **10.62 days** — significant impact on customer experience
- **AL (Alagoas)** state has the highest average delay — needs logistics attention
- Only **138 High Risk orders** identified — Risk Score model working effectively
- **Logistic Regression model** achieved **95.89% accuracy** in predicting delays

## 🔍 Key Features
- Delivery delay analysis across 96K+ orders
- Vendor performance evaluation & ranking
- Custom **Risk Score model** (Low / Medium / High)
- Delay prediction using Logistic Regression
